# Template 变更记录

## 2026-11-09

用户要求重新设计全部 UI，保留现有元素和功能，可以增加内容。

- `ClientUIUtils` 改为桌游风格主题，原有接口保持兼容，新增面板、标签、画布缩放和顶部提示。
- 重做主菜单、房间列表、房间和排行榜。房间界面按最大人数显示空座位，排行榜显示头像、奖牌并高亮本人。
- 统一房间更新逻辑，开局人数检查改用 `Config.game.minPlayers`。房主卡片的准备状态显示为已准备。
- 界面不再使用 Roblox 顶栏安全区，元素居中放置避开顶部按钮。头像在正方形约束下居中，房间卡片头像位于正中，名字在上、准备状态在下。
- 聊天框改为深色面板，可挂到宿主提供的 `ChatSlot`。系统 `Message` 提示改为顶部提示条。


按用户要求通过 Rojo 和 Studio MCP 重构及验证 Template。按确认方案使用 Roblox 聊天，并将比赛聊天限定为该场比赛的玩家。

- 远程实例改由服务器创建，客户端等待复制对象。修复排除指定玩家的广播方法。
- 使用原生 `TextChannel` 和 `TextChannelWindow`，移除原文转发 Remote。比赛销毁时清理频道。
- 比赛和房间 ID 改用 GUID。掉线处理基于房间当前关联的对局，支持宿主指定掉线中止策略。
- 房名由服务器根据 Roblox 显示名生成。大厅继续使用原有的默认命名，创建 Remote 的客户端文本不参与命名。
